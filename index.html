Сайт-библия игры. Доступ только для тех, кого впустил автор.
Введите код доступа.

Для просмотра без кода владелец может отправить ссылку «Поделиться». Коды хранятся в game-docs/src/config.json (SHA-256).
Если код потерялся — владелец добавляет новый в «Настройках → Доступ».
Можно войти по ссылке: #code=ВАШ-КОД (код подставится автоматически).
Если сеть до репозитория не работает — открой ?open=1: просмотр доступен, сохранение нет.
