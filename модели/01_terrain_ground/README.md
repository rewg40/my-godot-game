# 01_terrain_ground — Местность: земля и поверхность

**Сюда кладём:** грунт, траву, песок, камень, снег, склоны, холмы, дороги,
тропы — всё, что образует «пол» уровня и по чему ходят персонажи.

**Сюда не кладём:** острова целиком и воду (→ `02_islands/`), отдельно
стоящие камни и скалы (→ `03_cliffs_rocks/`), растения (→ `04_vegetation/`).
