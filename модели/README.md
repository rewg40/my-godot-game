# Модели — местность и острова

Библиотека 3D-моделей для игры. Всё в формате **glTF 2.0 Binary (`.glb`)**,
единица измерения — **метры**, ось **Y — вверх**. Все файлы **самодостаточны**:
текстуры и материалы вшиты внутрь `.glb`, никаких внешних зависимостей, —
модель можно скопировать одним файлом и она не сломается.

| | |
|---|---|
| Моделей всего | **862** (479 133 треугольника) |
| Kenney (CC0) | 633 |
| KayKit (CC0) | 221 |
| Сгенерировано скриптом | 8 |
| Текстур PNG | 4 |
| Объём папки | ~34 МБ |

Наглядное превью сгенерированных моделей — [`preview.png`](preview.png).

## Что куда класть — категории

| Папка | Что там лежит | Моделей |
|---|---|---|

| **`02_islands/`** | **Острова.** Готовые острова целиком (с подводным основанием), береговая линия, вода, реки, водопады. Сюда кладите любой новый остров, атолл, риф, скалу-островок и водные тайлы вокруг острова. | 97 |
| **`03_cliffs_rocks/`** | **Скалы и камни.** Утёсы, обрывы, валуны, горы, холмы-останцы, входы в пещеры. Всё, что ставится *на* местность как рельефная деталь. | 143 |
| **`04_vegetation/`** | **Растительность.** Деревья, пальмы, трава, цветы, пни, посевы. Всё живое, что растёт на острове. | 148 |
| **`05_buildings_structures/`** | **Постройки и конструкции.** Дома, башни, замки, стены, заборы, ворота, доки, мосты, платформы, маяки, палатки, статуи, флаги. Всё, что построено руками. | 250 |
| **`06_props_decor/`** | **Реквизит и декор.** Бочки, ящики, сундуки, корабли, пушки, оружие, облака, противники. Мелкие объекты, которые не относятся к рельефу. | 75 |
| `textures/` | Атласы паков (PNG) — нужны только если захотите делать свои тайлы в том же стиле. | 4 |
| `scripts/` | Скрипты скачивания, конвертации, генерации и проверки. | 8 |

В каждой папке категории лежит свой `README.md` с правилами раскладки.

**Как выбрать папку для новой модели:** «это земля, на которой стоишь?» → `01`.
«Кусок суши, окружённый водой?» → `02`. «Камень/скала/гора?» → `03`.
«Растение?» → `04`. «Построено руками?» → `05`. Остальное → `06`.

## Источники и префиксы файлов

| Префикс | Источник | Моделей |
|---|---|---|
| `hex_` | Kenney **Hexagon Kit** — гексагональные тайлы местности | |
| `nat_` | Kenney **Nature Kit** — скалы, камни, деревья, мосты | |
| `td_` | Kenney **Tower Defense Kit** — квадратные тайлы и склоны | |
| `pir_` | Kenney **Pirate Kit** — пальмы, песок, скалы, доки, корабли | 633 |
| `kay_` | **KayKit Medieval Hexagon Pack** — гекс-тайлы, берега, реки, горы, постройки 5 цветов | 221 |
| `gen_` | **Сгенерировано** скриптом `scripts/generate_islands.py` | 8 |

Префиксы нужны по двум причинам: одинаковые имена из разных паков (файл
grass.glb есть в трёх паках сразу) не затирают друг друга, и по имени сразу
видно происхождение модели. Полное соответствие «файл → пак → исходное имя»
лежит в **`inventory.json`**.

**Про `kay_`:** KayKit поставляется в glTF separate (`.gltf` + `.bin` + атлас
PNG), что неудобно для перетаскивания по одному файлу. Скрипт
`scripts/convert_kaykit.py` упаковал каждый набор в один `.glb` и вшил атлас
внутрь (он один на весь пак и весит 15 КБ). **Геометрия не изменялась** —
проверено биективной сверкой всех 221 модели с оригиналами по числу вершин,
индексов, границам и числу узлов.

У KayKit есть приятная деталь для острова: тайлы `coast` и `river` идут в двух
версиях — с водой (`kay_hex_coast_A.glb`) и **без воды** (`kay_hex_coast_A_waterless.glb`,
`kay_hex_river_D_waterless.glb`), чтобы подключить собственную анимированную воду.

## Сгенерированные модели местности и островов

Этих моделей нет ни в одном паке — они сделаны процедурно
(`scripts/generate_islands.py`, только стандартная библиотека Python).

| Файл | Что это | Размер (Ш×В×Г) |
|---|---|---|
| `01_terrain_ground/gen_terrain_large.glb` | Холмистая равнина, окрашена по биомам (песок → трава → скалы → снег) | 64.0 × 3.8 × 64.0 м |
| `01_terrain_ground/gen_terrain_small.glb` | Компактный чанк местности для сборки карты из кусков | 32.0 × 4.0 × 32.0 м |
| `01_terrain_ground/gen_hex_tiles.glb` | 4 гексагональных тайла ступенчатой высоты (0.2/0.6/1.0/1.6 м) | радиус 1 м |
| `02_islands/gen_island_a.glb` | Остров с пляжем и скалистым центром | 48.0 × 6.2 × 48.0 м |
| `02_islands/gen_island_b.glb` | Вулканический остров с кратером | 40.0 × 7.0 × 40.0 м |
| `02_islands/gen_atoll.glb` | Атолл: кольцо рифа вокруг лагуны (дно лагуны ниже уровня воды) | 56.0 × 3.9 × 56.0 м |
| `02_islands/gen_rock_islet.glb` | Маленький скалистый островок | 20.0 × 6.0 × 20.0 м |
| `02_islands/gen_island_cluster.glb` | Архипелаг: три острова на одной плите | 107.1 × 6.2 × 75.1 м |

**Масштаб согласован между всеми источниками:** и у Kenney, и у KayKit тайл =
1×1 м с подъёмом 0.2–0.8 м, дерево ≈ 1.5 м высотой; сгенерированные модели
деланы в той же шкале, так что их можно ставить в одной сцене без костылей.

У сгенерированных островов **уровень моря `y = 0`**, под водой — «юбка»
глубиной 2 м и плоское дно, поэтому стык с плоскостью воды не просвечивает.

## Как пользоваться в Godot 4

1. Скопируйте нужную папку (или всю `модели/`) в `res://` проекта.
2. Godot сам импортирует `.glb`. Два варианта:
   * **Перетащить в сцену** — получите `Node3D` с готовым мешем и материалом.
   * **Кодом:**
     ```gdscript
     var island := preload("res://модели/02_islands/gen_island_a.glb")
     var node := island.instantiate()
     add_child(node)
     ```
3. У сгенерированных (`gen_*`) моделей цвет «зашит» в вершины, поэтому для
   него нужен материал с `vertex_color_use_as_albedo = true`:
   ```gdscript
   var mat := StandardMaterial3D.new()
   mat.vertex_color_use_as_albedo = true
   $MeshInstance3D.material_override = mat
   ```
   У `hex_/nat_/td_/pir_/kay_` — обычные PBR-материалы с текстурой, ничего
   включать не нужно.
4. Для коллизий: `MeshInstance3D → правая кнопка → Create Trimesh Static Body`,
   либо `mesh.create_trimesh_shape()` в коде.

## Скрипты

| Скрипт | Зачем |
|---|---|
| `scripts/make_all.sh` | Пересобирает папку целиком: скачать → разложить → сконвертировать → сгенерировать → проверить → собрать инвентарь |
| `scripts/organize_models.py` | Раскладывает скачанные `.glb` Kenney по категориям |
| `scripts/convert_kaykit.py` | Собирает glTF separate KayKit в самодостаточные `.glb` (вшивает атлас) и раскладывает по категориям |
| `scripts/generate_islands.py` | Генерирует процедурные модели местности и островов (только stdlib) |
| `scripts/build_inventory.py` | Пересобирает `inventory.json` по фактическому содержимому папки |
| `scripts/validate_glb.py` | Проверяет каждый `.glb`: заголовок, чанки, accessor'ы, индексы, цепочку `material → texture → image` (только stdlib) |
| `scripts/verify_winding.py` | Проверяет ориентацию граней у `gen_*`-моделей (нужен `trimesh`) |
| `scripts/render_preview.py` | Рисует `preview.png` со всеми сгенерированными моделями |

Полная пересборка (сама скачает оба источника):

```bash
./модели/scripts/make_all.sh
```

Проверки:

```bash
python3 модели/scripts/validate_glb.py модели
# нужен venv: python3 -m venv .venv && .venv/bin/pip install trimesh networkx scipy
.venv/bin/python модели/scripts/verify_winding.py модели
```
