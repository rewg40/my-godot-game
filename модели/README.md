# Модели — местность и острова

Библиотека 3D-моделей для игры. Всё в формате **glTF 2.0 Binary (`.glb`)**,
единица измерения — **метры**, ось **Y — вверх**, у всех моделей есть нормали
и вертексные цвета (`COLOR_0`), так что они рендерятся даже без текстур.

| | |
|---|---|
| Моделей всего | **641** |
| Скачано (Kenney, CC0) | 633 |
| Сгенерировано скриптом | 8 |
| Текстур PNG | 3 |
| Объём папки | ~19 МБ (17 МБ — сами модели) |

Наглядное превью сгенерированных моделей — [`preview.png`](preview.png).

## Что куда класть — категории

| Папка | Что там лежит | Моделей |
|---|---|---|
| **`01_terrain_ground/`** | **Местность.** Грунт, трава, песок, камень, склоны, холмы, дороги и тропы. Это «пол» уровня — то, по чему ходят. Сюда же кладите новые тайлы поверхности, плиты земли, снежные и пустынные тайлы. | 121 |
| **`02_islands/`** | **Острова.** Готовые острова целиком (с подводным основанием), береговая линия, вода, реки, водопады. Сюда кладите любой новый остров, атолл, риф, скалу-островок и водные тайлы вокруг острова. | 51 |
| **`03_cliffs_rocks/`** | **Скалы и камни.** Утёсы, обрывы, валуны, горные пики, входы в пещеры. Всё, что ставится *на* местность как рельефная деталь. | 129 |
| **`04_vegetation/`** | **Растительность.** Деревья, пальмы, трава, цветы, пни, посевы. Всё живое, что растёт на острове. | 136 |
| **`05_buildings_structures/`** | **Постройки и конструкции.** Дома, башни, стены, доки, причалы, мосты, платформы, заборы, маяки, палатки, статуи. Всё, что построено руками. | 153 |
| **`06_props_decor/`** | **Реквизит и декор.** Бочки, ящики, сундуки, бутылки, пушки, лодки и корабли, инструменты, костры, противники, оружие. Мелкие объекты, которые не относятся к рельефу. | 51 |
| `textures/` | Текстуры паков Kenney (PNG). | 3 |
| `scripts/` | Скрипты скачивания, генерации и проверки (см. ниже). | 7 |

В каждой папке категории лежит свой `README.md` с подробным описанием,
какие именно модели туда относятся.

**Как выбрать папку для новой модели:** спросите «это земля, на которой
стоишь?» → `01`. «Это кусок суши, окружённый водой?» → `02`. «Это камень/скала?»
→ `03`. «Это растение?» → `04`. «Это построено?» → `05`. Всё остальное → `06`.

## Именование файлов

Префикс показывает происхождение модели:

| Префикс | Источник |
|---|---|
| `hex_` | Kenney **Hexagon Kit** — гексагональные тайлы местности |
| `nat_` | Kenney **Nature Kit** — скалы, камни, деревья, мосты |
| `td_` | Kenney **Tower Defense Kit** — квадратные тайлы и склоны |
| `pir_` | Kenney **Pirate Kit** — пальмы, песок, скалы, доки, корабли |
| `gen_` | **Сгенерировано** скриптом `scripts/generate_islands.py` |

Префиксы нужны, чтобы одинаковые имена из разных паков (файл grass.glb есть
и в Hexagon Kit, и в Nature Kit, и в Pirate Kit) не перезаписывали друг друга.
Полное соответствие «файл → пак → исходное имя» лежит в **`inventory.json`**.

## Сгенерированные модели местности и островов

Этих моделей нет ни в одном паке — они сделаны процедурно под эту игру
(`scripts/generate_islands.py`, только стандартная библиотека Python).

| Файл | Что это | Размер (Ш×В×Г) |
|---|---|---|
| `01_terrain_ground/gen_terrain_large.glb` | Холмистая равнина, окрашена по биомам (песок → трава → скалы → снег) | 64.0 × 3.8 × 64.0 м |
| `01_terrain_ground/gen_terrain_small.glb` | Компактный чанк местности для сборки карты из кусков | 32.0 × 4.0 × 32.0 м |
| `01_terrain_ground/gen_hex_tiles.glb` | 4 гексагональных тайла ступенчатой высоты (0.2 / 0.6 / 1.0 / 1.6 м) | радиус 1 м, как у `hex_grass.glb` |
| `02_islands/gen_island_a.glb` | Остров с пляжем и скалистым центром | 48.0 × 6.2 × 48.0 м |
| `02_islands/gen_island_b.glb` | Вулканический остров с кратером | 40.0 × 7.0 × 40.0 м |
| `02_islands/gen_atoll.glb` | Атолл: кольцо рифа вокруг лагуны (дно лагуны ниже уровня воды) | 56.0 × 3.9 × 56.0 м |
| `02_islands/gen_rock_islet.glb` | Маленький скалистый островок | 20.0 × 6.0 × 20.0 м |
| `02_islands/gen_island_cluster.glb` | Архипелаг: три острова на одной плите | 107.1 × 6.2 × 75.1 м |

**Масштаб согласован со скачанными паками:** тайл Kenney = 1×1 м с подъёмом
0.2–0.8 м, дерево ≈ 1.5 м высотой — и все `gen_*` модели сделаны в той же шкале,
так что их можно ставить рядом без костылей с масштабом.

У сгенерированных островов **уровень моря `y = 0`**, под водой — «юбка»
глубиной 2 м и плоское дно, поэтому стык с плоскостью воды не просвечивает.

## Как пользоваться в Godot 4

1. Скопируйте нужную папку (или всю `модели/`) в `res://` проекта.
2. Godot сам импортирует `.glb`. Дальше два варианта:
   * **Перетащить в сцену** — получите `Node3D` с готовым мешем.
   * **Кодом:**
     ```gdscript
     var island := preload("res://модели/02_islands/gen_island_a.glb")
     var node := island.instantiate()
     add_child(node)
     ```
3. Вертексные цвета видны материалом с `vertex_color_use_as_albedo = true`:
   ```gdscript
   var mat := StandardMaterial3D.new()
   mat.vertex_color_use_as_albedo = true
   $MeshInstance3D.material_override = mat
   ```
4. Для коллизий: `MeshInstance3D → правая кнопка → Create Trimesh Static Body`,
   либо `mesh.create_trimesh_shape()` в коде.

## Скрипты

| Скрипт | Зачем |
|---|---|
| `scripts/make_all.sh` | Пересобирает папку целиком: скачать → разложить → сгенерировать → проверить → собрать инвентарь |
| `scripts/organize_models.py` | Раскладывает скачанные `.glb` по категориям |
| `scripts/generate_islands.py` | Генерирует процедурные модели местности и островов (только stdlib) |
| `scripts/build_inventory.py` | Пересобирает `inventory.json` по фактическому содержимому папки |
| `scripts/validate_glb.py` | Проверяет целостность каждого `.glb`: заголовок, чанки, accessor'ы, индексы (только stdlib) |
| `scripts/verify_winding.py` | Проверяет ориентацию граней у `gen_*`-моделей (нужен `trimesh`) |
| `scripts/render_preview.py` | Рисует `preview.png` со всеми сгенерированными моделями |

Полная пересборка (скачает паки Kenney во временный каталог):

```bash
./модели/scripts/make_all.sh
```

Проверки:

```bash
python3 модели/scripts/validate_glb.py модели
# нужен venv: python3 -m venv .venv && .venv/bin/pip install trimesh networkx scipy
.venv/bin/python модели/scripts/verify_winding.py модели
```
