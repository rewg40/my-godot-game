# Ассеты полигона

Сюда кладутся модели. В git они не попадают: каждый GLB весит 70–130 МБ,
а GitHub не принимает файлы больше 100 МБ.

## Что должно лежать

| Файл | Откуда | Обязателен |
|---|---|---|
| `zombie.glb` | `ZOMBI.7z.001…004` из корня репозитория | да |
| `character.glb` | `персонаж 1.7z.001…003` из корня репозитория | да |
| `island.glb` | `остров 1.7z.001…002` из корня репозитория | один из двух |
| `island_improved.glb` | «2 остров улучшенный.glb» от автора ассетов | один из двух |

Дальше генератор пишет рядом:

| Файл | Что это |
|---|---|
| `zombie_parts.glb` | зомби, нарезанный на 5 поверхностей: тело, две руки, две ноги |
| `zombie_parts.json` | шарниры и габариты частей (в метрах модели) |
| `character_parts.glb` | то же для медика |
| `character_parts.json` | шарниры медика |

## Как получить

```bash
python -m pip install py7zr numpy
python tools/prepare_assets.py
```

Скрипт сам склеит `*.7z.001…` из корня, распакует модели, нарежет их и
напечатает отчёт: сколько треугольников попало в каждую часть и где шарниры.

Если архивов под рукой нет — положите готовые GLB в эту папку и запустите:

```bash
python tools/prepare_assets.py --skip-unpack
```

## Подгонка реза

Правила лежат в `tools/split_profiles.json`. Ключи:

| Ключ | Смысл |
|---|---|
| `hip_y` | доля роста, ниже которой начинаются ноги |
| `shoulder_y` | доля роста, на которой плечи |
| `arm_x` | насколько плечо отстоит от центра по X |
| `arm_radius` | радиус «трубы» вокруг оси руки |
| `arm_taper` | во сколько раз труба расширяется к кисти |
| `center_x` | смещение центра корпуса (у сгорбленного зомби оно не нулевое) |
| `yaw` | доворот модели, чтобы она смотрела вперёд по −Z |

После правки — снова `python tools/prepare_assets.py --skip-unpack`. В игре
нажмите F3: зоны попадания подсвечиваются красным, сразу видно, куда попал рез.

## Почему рез считается заранее

Модели — скульптуры на 1.5 млн треугольников без скелета. Резать их в GDScript
на старте значило бы несколько секунд ожидания на каждый запуск, поэтому
разметка считается один раз в Python (numpy), а движок получает готовый GLB
с пятью поверхностями и JSON с шарнирами.
