# Целые вкладки (замена целиком)

Эти файлы — копии из ветки `arena/087e4771-my-godot-game`. Они нужны там, где построчный
перенос бессмысленен: модель вкладки отличается, и бандл честно сообщает
`ПРОПУСК: в целевой вкладке нет понятий …`.

| Файл | Почему целиком | Что теряется при замене |
|---|---|---|
| `mech_character.json` | здесь «происхождение + практика + специализация», в `73c7370f` — «пирамида прогресса, ветки и ранги». Модели несовместимы | разделы старой модели: «Пирамида прогресса», «Ветки и ранги», «Список анимаций персонажа (v1)», «Технический контур» |
| `mech_zombies.json` | можно не менять целиком: бандл переносит всё сам (проверено на `c770567`) | — (только если нужна полная идентичность) |
| `mech_craft.json` | то же: бандл переносит разделы УТ и запаха | — |

**Как применять.** Скопировать поверх `game-docs/src/content/<имя>.json` в целевой ветке,
затем обязательно:

```bash
python3 -c "import json,sys; json.load(open('game-docs/src/content/mech_character.json',encoding='utf-8'))"
npm test --prefix game-docs
```

**Внимание:** замена `mech_character.json` стирает старую модель вкладки целиком. Если в
`73c7370f` есть ценные наработки по «пирамиде прогресса», сначала вынесите их в отдельный
раздел или черновик — иначе они пропадут.
