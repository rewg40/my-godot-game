# Модели

В этой папке лежат тяжёлые GLB-модели. Они **не хранятся в git** (см. `.gitignore`):
суммарно ~660 МБ, а `остров/2 остров улучшенный.glb` вообще превышает лимит
GitHub в 100 МБ на файл.

## Как положить модели сюда

```bash
python tools/unpack_assets.py
```

Скрипт склеит разрезанные архивы из корня репозитория и разложит файлы:

| Файл в этой папке | Откуда берётся | Что делает в игре |
|---|---|---|
| `zombie.glb` | `ZOMBI.7z.001…004` | тело зомби (масштаб 1.75) |
| `island.glb` | `остров 1.7z.001…002` | рельеф острова вместо процедурного |
| `character.glb` | `персонаж 1.7z.001…003` | пока не используется, лежит для будущих классов |
| `sword.glb` | `предмет/` из репозитория ассетов | модель клинка «Дракон» у предмета |

Если файлов нет — игра работает: рельеф генерируется шумом, а зомби собираются
из примитивов. Подробности — в `../../ASSETS.md`.
