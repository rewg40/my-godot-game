# Данные мира

Здесь лежат данные, которые не хранятся в git из-за размера.

| Файл | Что это | Как получить |
|---|---|---|
| `vegetation_points.json` | 148 936 точек леса, травы и камней из репозитория ассетов | `python tools/unpack_assets.py --assets-repo <путь к копии репозитория pepel-i-zvezdy>` |

Формат: массив `{"t": вид, "x": …, "y": …, "z": …, "s": масштаб}`.
Если файла нет, растительность расставляется процедурно по рельефу.
