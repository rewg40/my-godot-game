# Пепел и Звёзды

3D-игра о выживании на заражённом острове. Проект на **Godot 4** (GDScript):
процедурный остров, день и ночь, зомби, крафт, костры, четыре игровых класса
и сохранение забега.

> Играбельный прототип: запускается сразу, без единого внешнего ассета —
> рельеф, растительность и тела зомби генерируются кодом. Если положить
> GLB-модели из репозитория ассетов, они подхватятся автоматически
> (см. [ASSETS.md](ASSETS.md)).

## Быстрый старт

1. Открыть Godot 4.4+ → **Import** → выбрать `pepel-i-zvezdy/project.godot`.
2. Нажать **F5**.

```bash
# из корня этого репозитория
godot --path pepel-i-zvezdy
```

Ассеты необязательны. Если хочется настоящий остров и зомби из моделей:

```bash
python -m pip install py7zr
python pepel-i-zvezdy/tools/unpack_assets.py
```

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` / стрелки | идти |
| `Shift` | бежать (тратит силы) |
| `Ctrl` | присесть |
| `Space` | прыжок |
| `E` | подобрать / взаимодействовать |
| `ЛКМ` | удар оружием |
| `1…5` | быстрое использование слота |
| `Tab` | рюкзак |
| `C` | крафт |
| `Esc` | пауза, сохранение, настройки |

Раскладка регистрируется кодом (`scripts/autoload/input_setup.gd`) — физические
клавиши, а не символы, поэтому работает на любой раскладке.

## Что уже работает

**Выживание.** Шесть шкал: здоровье, сытость, жажда, силы, заражение, тепло.
Голод и жажда убывают постоянно, заражение набирается от укусов и грязной воды,
тепло уходит ночью, если рядом нет костра. При нуле здоровья — экран смерти
со статистикой забега.

**Остров.** Процедурный рельеф 240 × 240 м из шума: пляжи, лес, скалы, снежные
вершины, вода по краям. Вершины раскрашиваются по высоте, поэтому переходы
биомов видны без текстур. Один `seed` — один и тот же остров, это же используется
для загрузки сохранения.

**Растительность.** До 14 000 кустиков травы, деревья, кустарники и камни —
всё в `MultiMesh`, то есть в несколько draw call. Если найден файл точек
`растительность_точки.json` из репозитория ассетов (148 936 объектов),
расстановка берётся из него.

**Сутки.** Полный цикл — 10 минут. Солнце и луна двигаются по небу, меняются
цвет неба, туман, энергия света. Ночью видно звёзды (настоящая геометрия,
а не текстура) и падающий пепел; зомби в темноте агрессивнее, а тепло уходит
вдвое быстрее.

**Зомби.** Ходоки и бегуны, погоня, расхождение, обход препятствий щупами,
удары с кулдауном, вспышка при попадании, лут с трупа. Спавн держит популяцию
и наращивает её каждую ночь; далёкие зомби убираются.

**Крафт.** 7 рецептов: бинт, факел, труба, набор для костра, антибиотики,
чистая вода (только у костра) и клинок «Дракон» (тоже у огня). Инженер крафтит
на 25% дешевле.

**Классы.** Медик, инженер, строитель, военный — разные стартовые наборы,
множители лечения, урона и заражения, разное максимальное здоровье.

**Сохранение.** JSON в `user://saves/slot1.json`: день, время, игрок, инвентарь,
статистика, поставленные костры, seed мира. Автосохранение на рассвете плюс
кнопка в паузе.

## Архитектура

**Код вместо сцен.** `.tscn` — это узел и скрипт; всё остальное (камера, лучи,
коллайдеры, интерфейс, рельеф) собирается в `_ready()`/`setup()`. Так проект
читается как обычный код, диффы остаются маленькими, а сцены не ломаются при
ручном редактировании. Если захочется править в редакторе — узлы создаются
с понятными именами (`Head`, `Camera`, `InteractRay`, `Survival`, `Inventory`).

**Автозагрузки.** `GameState` — состояние забега, часы, пауза и шина сигналов;
`ItemDB` — предметы, рецепты, классы; `SaveSystem` — сохранения и настройки;
`InputSetup` — раскладка.

**Сигналы вместо ссылок.** Игрок не знает про HUD, HUD — про мир: общение идёт
через `GameState.message`, `player_spawned`, `run_ended`, `day_started`,
`night_fell`.

**Мир из seed.** `World.setup(seed, data)` строит остров детерминированно,
поэтому сохранение — это несколько килобайт JSON, а не слепок сцены.

## Известные ограничения

- Модели из репозитория ассетов — статичные меши без скелета и анимаций,
  поэтому движение зомби имитируется процедурно (покачивание, наклон).
  Для полноценных анимаций нужен риггованный GLB.
- Звука пока нет: ни шагов, ни ветра, ни ударов.
- Зомби ходят по прямой с объездом препятствий щупами, без `NavigationRegion3D`.
- Нет строительства баз: костёр — единственный объект, который ставится в мире.
