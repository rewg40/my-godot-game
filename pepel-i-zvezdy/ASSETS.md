# Ассеты: откуда берутся и как подключить

Проект полностью играбелен **без** внешних моделей: рельеф, растительность,
зомби и предметы генерируются кодом. Настоящие модели подключаются одной
командой и подхватываются автоматически.

## Источники

1. **Этот репозиторий** — разрезанные архивы в корне:

   | Архив | Внутри | Размер архива |
   |---|---|---|
   | `ZOMBI.7z.001…004` | `ZOMBI.glb` (90 МБ) | 66 МБ |
   | `остров 1.7z.001…002` | `остров 1.glb` (66 МБ) | 40 МБ |
   | `персонаж 1.7z.001…003` | `персонаж 1.glb` (66 МБ) | 42 МБ |

2. **[rewg40/pepel-i-zvezdy](https://github.com/rewg40/pepel-i-zvezdy)** —
   репозиторий ассетов «Пепел и Звёзды»: референсы, маски биомов, рендеры
   «до/после» и `остров/растительность_точки.json` на 148 936 точек.

## Распаковка

```bash
python -m pip install py7zr
python tools/unpack_assets.py
# вместе с точками растительности из локальной копии репозитория ассетов:
python tools/unpack_assets.py --assets-repo "D:/my games/Godot/Пепел и Звёзды"
```

Получится:

```
assets/models/zombie.glb      из ZOMBI.7z.*
assets/models/island.glb      из «остров 1.7z.*»
assets/models/character.glb   из «персонаж 1.7z.*»
assets/data/vegetation_points.json   (если указан --assets-repo)
```

Вручную то же самое:

```bash
cat "ZOMBI.7z.00"* > /tmp/zombi.7z
7z x /tmp/zombi.7z -o pepel-i-zvezdy/assets/models
mv pepel-i-zvezdy/assets/models/ZOMBI.glb pepel-i-zvezdy/assets/models/zombie.glb
```

## Что это за модели (по метаданным GLB)

Все три файла собраны Blender 4.0 glTF I/O и устроены одинаково:

- один узел (`node_0`) с поворотом 90° вокруг X — модель уже стоит «ногами вниз»
  по Y, ничего крутить в Godot не нужно;
- один меш, один материал, PBR-текстуры (normal / base color / metallic-roughness);
- **нет скелета и анимаций** — это статичные скульптуры;
- габариты около 1 юнита, то есть модель нужно масштабировать.

Отсюда правила в коде:

| Модель | Масштаб | Как используется |
|---|---|---|
| `zombie.glb` | ×1.75 (≈1.8 м) | тело зомби; «анимация» — покачивание и наклон |
| `island.glb` | автоматически под 240 м | рельеф вместо процедурного; высоты берутся рейкастами |
| `character.glb` | ×1.75 | пока не используется — место для модели игрока |
| `sword.glb` | как есть | модель предмета «Клинок „Дракон“» |

`sword.glb` берётся из папки `предмет/` репозитория ассетов (в самом репозитории
он исключён через `.gitignore` из-за веса). Достаточно положить файл в
`assets/models/sword.glb` — предмет сам начнёт использовать модель.

Проверить, что подхватилось, можно по консоли: при старте печатается число
инстансов растительности, а в сцене появляются узлы `TerrainModel` (остров)
и модели внутри `Visual` (зомби).

## Точки растительности

`растительность_точки.json` — массив объектов:

```json
[{"t": "tuft", "x": 94.15, "y": 794.83, "z": 1505.97, "s": 0.778}]
```

- `t` — вид: `tuft` (трава, 141 148 шт.), `pine_a`/`pine_b` (2 532 / 1 330),
  `decid`/`decid_b` (1 357 / 1 279), `bush` (1 089), `pine_snow` (63),
  `rock_a`/`rock_b`/`rock_c` (37 / 53 / 48);
- `x`, `y` — горизонтальные координаты в масштабе исходной модели (±12 000),
  `z` — высота (29…2 227), `s` — масштаб;
- вертикаль берётся из рельефа игры, а не из `z`: так точки не висят в воздухе,
  если остров построен процедурно.

`scripts/world/vegetation.gd` нормализует координаты под карту, отбрасывает
точки ниже уровня воды и прореживает траву до 14 000 инстансов (остальные виды
ставятся полностью). Каждый вид — отдельный `MultiMeshInstance3D`.

## Почему GLB не в git

Суммарный вес моделей — около 660 МБ, а `остров/2 остров улучшенный.glb`
превышает лимит GitHub в 100 МБ на файл. Поэтому:

- в репозитории лежат только разрезные архивы;
- `assets/models/*.glb`, `assets/models/*.gltf`, `assets/data/*.json`
  исключены через `.gitignore`;
- распаковка — локальная операция (`tools/unpack_assets.py`).

## Производительность

- Остров: ~22 000 вершин, ~44 000 треугольников, коллизия `ConcavePolygonShape3D`.
- Растительность: до ~20 000 инстансов в 7 `MultiMesh`.
- Звёзды: 700 сфер, пепел: 420 квадов, обновляются кодом каждый кадр.
- Импорт GLB в Godot занимает несколько минут и создаёт кэш `.godot/`
  (он тоже в `.gitignore`).
