# Заявки агенту

Кидает сюда сайт (внизу → «Запросы агенту», в редакторе → «Сохранить и отправить ИИ») и агент читает отсюда.

- Файл: `<id>-короткий-slug.md`. Старые заявки могли называться `NNNN-slug.md`.
- Новая заявка из редактора содержит: `status: pending`, вкладку, файл, область обработки (`scope`),
  запрос автора, контекст вкладки, критерии готовности и инструкцию агенту. Это задача на целостную
  переработку, а не просто заметка.
- Агент: читает → правит нужный `content/*.json` и связанные вкладки → валидирует JSON →
  выполняет `npm test --prefix game-docs` → коммит → пуш → переносит файл в `done/` с итогом
  в конце (изменённые файлы, числа, оставшиеся вопросы).
- Правила правки и стандарт детализации: `../../docs/AGENT-GUIDE.md`.
- Заявку можно прислать и в чат Arena — адрес сайта при этом не нужен, достаточно
  назвать раздел (например: «в Погоду — 4 сезона таблицей эффектов»).
