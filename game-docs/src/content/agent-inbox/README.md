# Заявки агенту

Кидает сюда сайт (внизу → «Запросы агенту») и агент читает отсюда.

- Файл: `NNNN-короткий-slug.md`, внутри: что сделать, куда отнести (вкладка), срок.
- Агент: читает → правит нужный `content/*.json` → валидирует JSON → коммит → пуш →
  переносит файл в `done/NNNN-....md` с итогом в конце файла.
- Правила правки и стандарт детализации: `../../docs/AGENT-GUIDE.md`.
- Заявку можно прислать и в чат Arena — адрес сайта при этом не нужен, достаточно
  назвать раздел (например: «в Погоду — 4 сезона таблицей эффектов»).
