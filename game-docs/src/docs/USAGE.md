# Как пользоваться сайтом (для автора)

Сайт-библия игры живёт вечно на GitHub Pages: **https://rewg40.github.io/my-godot-game/**
Данные — в твоём репозитории `rewg40/my-godot-game`, в папке `game-docs/`. Это и есть «подключение» агента: он правит те же файлы, которые читает сайт.

## 1. Вход и запрет чужих

- Открываешь сайт → появляется запрос **кода доступа**. Твой личный код: `ZOMBI-2026` (это код владельца: он может добавлять и отзывать доступ).
- Кому разрешить: ⚙ Настройки → «Доступ» → «Сгенерировать» → отправить получившийся код человеку → «Отправить config.json в репозиторий». Коды хранятся как SHA-256, в коде сайта их не видно.
- Отозвать доступ: удалить строку хеша из списка и закоммитить config.json снова.
- Если токен не задан, можно читать; писать — только если в ⚙ задан твой GitHub-токен с правом `repo`/Contents: Write.

## 2. Три вкладки

| Вкладка | Что внутри |
| --- | --- |
| **Сценарий** | логлайн, мир, таймлайн, персонажи, акт I–III, сцены, концовки, правила мира, глоссарий |
| **Механика** | 13 подвкладок: Персонаж · Крафт · Погода · NPC и фракции · Квесты · Локации · Разрушаемые объекты · **Физика** · ИИ монстров · Бой и оружие · Инвентарь и лут · 3D-модели и ассеты · Аудио, UI, структура проекта |
| **Картинки / превью** | галерея концептов/скриншотов + список 3D-моделей с вьювером (GLB крутится прямо на сайте) |

## 3. Как править текст

1. Наведи курсор на любой блок → справа появятся кнопки `✎ ✕ ↑ ↓ ＋`.
2. `✎` — редактировать. Формат простой, как в Markdown:
   - пустая строка — новый абзац;
   - `- ` список, `1. ` нумерованный, `- [ ]` чек-лист;
   - таблица: первая строка — заголовки через `|`, вторая — `---`;
   - ` ``` ` — код, `> ` — врезка, `## ` — заголовок подраздела;
   - `![подпись](images/preview/file.webp)` — картинка.
3. Правки сразу сохраняются в браузере (жёлтая плашка «есть несохранённые правки»).
4. `⤒ Сохранить в GitHub` (или `Ctrl+S`) — коммит в репозиторий. Через ~1 минуту изменения видны всем, у кого есть код.
5. Если правка не нужна: «Отменить правки» — вернётся версия из репозитория.

## 4. Картинки и 3D-модели

- **Картинка:** вкладка «Картинки / превью» → «＋ Картинка» → перетащить файл. Сайт сожмёт (≤ 1400 px, WebP), зальёт в `game-docs/src/content/images/…` и добавит в реестр.
- Нет токена? Тогда «вместо файла — ссылка»: дай URL `https://raw.githubusercontent.com/rewg40/my-godot-game/<ветка>/game-docs/src/content/images/...`, а файл пусть положит агент.
- **3D-модель:** «＋ 3D-модель» → GLB/GLTF/FBX/OBJ (до 24 МБ) → попадёт в `game-docs/src/content/models/` + запись в `models.json`. Кнопка «👁 превью» крутит модель на сайте.

## 5. Как работать с агентом

- Пишешь агенту сюда, в чат Arena: «добавь в Погоду 4 сезона и таблицу эффектов» — он откроет `game-docs/src/content/mech_weather.json`, допишет блоки, закоммитит, запушит; сайт обновится сам.
- Или через сайт: «Запросы агенту» (внизу) → текст → «Отправить агенту» → появится файл в `game-docs/src/content/agent-inbox/`. Дальше скажи агенту: «разбери inbox».
- Полная инструкция для агента (формат JSON, стандарт детализации, правила Godot): ссылка «Инструкция для агента» внизу сайта и файл `game-docs/src/docs/AGENT-GUIDE.md`.

## 6. Где что лежит в репозитории

```
game-docs/                 ← «папка проекта документации», отдельно от архивов и Godot-проекта
├── src/                   ← сайт (index.html, app.css, app.js, config.json)
│   ├── content/           ← ВЕСЬ КОНТЕНТ: scenario.json, mech_*.json, preview.json, images.json, models.json
│   │   ├── images/        ← картинки для галереи
│   │   ├── models/        ← 3D-модели (превью)
│   │   └── agent-inbox/   ← твои запросы агенту
│   └── docs/              ← эта инструкция + AGENT-GUIDE.md
└── README.md
.github/workflows/deploy-docs-site.yml   ← автопубликация на Pages
```

Архивы `ZOMBI.7z.*`, `остров 1.7z.*`, `персонаж 1.7z.*` в корне не трогаем: они нужны как исходники. Когда будешь готов — агент предложит перейти на Git LFS, чтобы репозиторий не раздувался.

## 7. Частые вопросы

- **Сайт не обновился после сохранения.** Коммит есть, а Pages нет? Подожди минуту; «↻ Обновить» подтянет из репозитория. Проверить сборку: `gh run list --workflow "Deploy docs site (ZOMBI bible)"`.
- **Пишет 404/403 при сохранении.** Нет токена, токен без прав на запись, или указана чужая ветка. ⚙ → «GitHub».
- **Хочу, чтобы контент писался в main, а не в рабочую ветку.** Поменяй ветку в ⚙ (например `main`) — тогда сайт будет читать/писать там, а агент продолжит на своей ветке; чтобы не разъезжалось, держи одну ветку-источник.
- **Картинка не показывается.** Значит файл ещё не долетел на Pages или путь в `images.json` не совпадает с реальным. Путь всегда относительно `content/`.
- **Открыть локально:** `cd game-docs/src && python3 -m http.server 8081` → http://localhost:8081 (без сервера и токена сайт работает в режиме «только чтение + черновики»).
