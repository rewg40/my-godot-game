# Осколки цивилизации — первый остров (3D)

Играбельная первая глава survival/RPG с крафтом и защитой поселения по сценарию [`docs/game_design_ru.txt`](docs/game_design_ru.txt). Это **не вся история про восемь островов**: в проекте реализован первый остров, от пробуждения на берегу до восстановления маяка и подготовки лодки.

## Запуск

1. Установите **Godot 4.3** (или совместимую версию Godot 4).
2. Импортируйте `project.godot` через менеджер проектов Godot и дождитесь импорта GLB-моделей.
3. Запустите проект клавишей **F5**. Все необходимые ресурсы находятся в репозитории.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение относительно камеры | WASD или стрелки |
| Повернуть и наклонить камеру | удерживать правую кнопку мыши и двигать мышь (наклон 30–75°) |
| Приблизить или отдалить камеру | колесо мыши |
| Бег | Shift |
| Прыжок | пробел |
| Атака | левая кнопка мыши или F |
| Взаимодействие | E |
| Крафт / инвентарь | C / Tab |
| Карта | M |
| Еда / вода / бинт | 1 / 2 / 3 |
| Пауза / сохранить | Esc / F5 |

## Что реализовано

- Настоящий 3D-мир: объёмный рельеф и море, высокая поворачиваемая перспективная камера, перемещение и прыжки с физикой. Персонажи и зомби используют скелетные анимации; все заражённые используют адаптированную модель, предоставленную пользователем.
- Визуальное направление вдохновлено HumanitZ: приглушённый свет и туман, фототекстуры грунта и асфальта, растительность, заброшенные машины и здания. Ресурсы самой HumanitZ не используются; графика остаётся независимым игровым прототипом, а не точной копией коммерческой игры.
- «Очаг», отель «Аврора», аэродром, лес, пещеры, маяк и берег; Марта, Борг, Лина, Тим и Гром.
- Добыча дерева, камня, металлолома, ткани и ягод; рецепты лечения, оружия и материалов. Бита из крафта использует предоставленную модель, закреплена в руке и имеет анимацию удара. Здоровье, выносливость, голод, жажда и суточный цикл.
- Три оборонительные башни, нападение пяти заражённых на поселение, враждебные патрули и два босса.
- Основная цепочка первого острова: оборона, ключ-карта, сейф отеля с первым фрагментом кода, детали маяка и лодка. Есть также небольшое поручение Тима.
- Карта, указатель задания, автосохранение и ручное сохранение. Координаты старых 2D-сохранений читаются как положение на новой 3D-карте.

Файлы сохранений Godot размещает в `user://`, вне репозитория. «Новая игра» просит подтверждение перед заменой существующего сохранения.

## Проверка

Для автоматической проверки нужен Godot 4.3:

```sh
godot --headless --editor --path . --quit
godot --headless --path . --script res://tests/smoke_test.gd
```

Smoke-тест использует отдельный тестовый слот и не перезаписывает обычные сохранения. Он проверяет 3D-рельеф, материалы, высокую камеру, растительность, анимированную модель, движение и прыжок, интерфейс, бой, квесты, защиту лагеря, крафт и сохранения. GitHub Actions также запускает импорт и тест на официальной сборке Godot 4.3.

Источники моделей, музыки, звуков и известные условия их использования перечислены в [`docs/ASSET_CREDITS.md`](docs/ASSET_CREDITS.md).
