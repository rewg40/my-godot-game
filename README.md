# my-godot-game

## 3D-модели

Библиотека моделей местности и островов лежит в [`модели/`](модели/README.md):
641 файл `.glb` (633 скачаны из паков Kenney по лицензии CC0, 8 сгенерированы
процедурно), разложенных по категориям — местность, острова, скалы,
растительность, постройки, реквизит.

Как пользоваться и как пересобрать папку — в [модели/README.md](модели/README.md).
