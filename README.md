# my-godot-game

## 3D-модели

Библиотека моделей местности и островов лежит в [`модели/`](модели/README.md):
**862 файла `.glb`**, разложенных по шести категориям — местность, острова,
скалы, растительность, постройки, реквизит.

Источники (все — CC0 1.0, можно использовать свободно, в том числе в
коммерческих проектах):

| | |
|---|---|
| Kenney — Hexagon / Nature / Tower Defense / Pirate Kit | 633 модели |
| KayKit — Medieval Hexagon Pack | 221 модель |
| сгенерировано процедурно (`scripts/generate_islands.py`) | 8 моделей |

Как пользоваться в Godot 4 и как пересобрать папку — в
[модели/README.md](модели/README.md).
