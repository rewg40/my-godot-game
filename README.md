# my-godot-game

Разрушенный город + остров с биомами для Godot 4.3+. Проект собран автоматически
из сгенерированных ассетов и моделей из архивов репозитория.

## Структура

- `assets/city/` — 46 рендеров зданий/сооружжений + 12 интерьеров (изометрия 3/4, серый фон)
- `assets/island/` — остров: референс с 4 биомами + 4 сектора-«дольки»
- `assets/textures/` — бесшовные PBR-текстуры: `albedo/`, `normal/`, `roughness/`
- `assets/models/` — распакованные GLB (island, zombi, character); **в git не коммитятся**,
  восстанавливаются командой `python3 scripts/extract_models.py` (нужен `pip install py7zr`)
- `materials/` — 10 материалов StandardMaterial3D (albedo+normal+roughness)
- `scenes/main.tscn` — главная сцена: остров (scale 100), город, актёры, свет, камера
- `scenes/material_showcase.tscn` — стенд материалов + 4 биома плитами
- `scripts/city_placer.gd` — автосборка: ставит здания-спрайты и актёров на поверхность
  острова рейкастом вниз, наводит изометрическую камеру
- `scripts/build_godot_project.py` — регенерация материалов/.import/стенда из текстур
- `scripts/make_pbr_maps.py` — деривация normal/roughness из albedo
- `prompts/` — все промты (город, остров, текстуры) с правилами стиля и сборки

## Запуск

1. Открыть папку репозитория в Godot 4.3+ — редактор сам импортирует текстуры и GLB.
2. Если `assets/models/` пустой: `python3 scripts/extract_models.py`.
3. F5 — главная сцена: остров с расставленным городом, персонажем и зомби.

## Заметки по сборке

- Остров из `island.glb` масштабируется в 100× (исходник ~1.1 юнита в диаметре).
- Здания — Sprite3D с поворотом `(-32°, 45°, 0)` под камеру рендеров; `pixel_size 0.015`
  даёт ~15 юнитов на 5 этажей; низ спрайта ставится на поверхность острова рейкастом.
- Свет сцены (Sun `-50°/-35°`, серый ambient) совпадает со светом рендеров.
- Раскладка города правится в таблице `LAYOUT` в `scripts/city_placer.gd`
  (доли радиуса острова), актёры — в `ACTORS`.
